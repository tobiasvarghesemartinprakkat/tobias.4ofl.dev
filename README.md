# Tobias Varghese — Reel Creator Showcase

A high-performance portfolio and reel showcase web application for reel creator Tobias Varghese (Kerala, India).

## Features

- **Interactive Hero**:
  - High-impact display typography (`Anton` + `Montserrat`).
  - Monochromatic cutout portrait with radial mouse-tracking color reveal lens.
  - Smooth scroll parallax animations.
- **Reel Showcase Grid**:
  - Filterable/playable video showcase cards with tags and smooth hover states.
- **Theme Switcher**:
  - Dynamic dark/light mode toggle powered by the native View Transitions API with circular ripple effect.
- **Pages**:
  - **Home** (`/`): Dynamic hero section with scroll-to-content preview.
  - **Content** (`/content`): Full reel gallery with video/card views.
  - **About** (`/about`): Biography and creator background.
  - **Contact** (`/contact`): Direct contact details, email (`tobias@4ofl.dev`), and social channels.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **State & Data**: [TanStack Query](https://tanstack.com/query)

## Getting Started

### Prerequisites

- Node.js (v18+) or Bun

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
